新手使用说明
  1. 第一次使用请保持默认路径，直接点击“运行测试”。
  2. 运行成功后，输出目录会生成 run.csv 和 report.md。
  3. 点击“查看报告 / 文件”里的“加载文件”，就可以看到报告内容。
  4. 想看某个信号的历史值，使用“按时间 / 信号查询”。
  5. 把鼠标移到任何输入框或按钮上，会显示对应说明。

⚙️ 运行测试

填写要运行的测试文件，新手保持默认即可。

🔎 按时间 / 信号查询

从已经生成的 CSV 里查询某个信号在某段时间内的值。

📄 查看报告 / 文件

查看运行后生成的报告或 CSV 文件。
