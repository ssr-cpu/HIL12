# 团队分工文件索引

本目录仅用于方便查看“谁负责哪些文件”，不改变原工程的编译结构。实际源码仍在 `src/`、`include/`、`tests/` 中，`团队分工文件` 下是同一批文件的分类副本。

| 文件夹 | 负责人角色 | 负责内容 |
|---|---|---|
| `01_项目经理_架构` | 1 项目经理/架构 | 公共基础、日志、虚拟时间、执行器、CLI、主流程、设计文档、需求追踪 |
| `02_ECU开发` | 2 ECU 开发 | 信号注册表、虚拟 ECU 状态机、周期任务、安全输出 |
| `03_总线开发` | 3 总线开发 | 帧结构、CRC、编码解码、帧队列、丢失/延迟/篡改 |
| `04_测试引擎` | 4 测试引擎 | 脚本解析、故障注入、断言、步骤执行 |
| `05_数据质量` | 5 数据质量 | 配置、CSV、数据记录、查询、报告 |
| `06_测试经理` | 6 测试经理 | 测试入口、构建脚本、Makefile、CMake、Sanitizer、测试报告 |

## 查看方式

- 想看某个人的全部文件，直接打开对应人名文件夹。
- 每个文件夹内都包含该角色负责的 `.c`、`.h` 和角色说明文档。
- `hil_executor` 属于项目经理/架构主责，测试引擎协作；需要看执行流程时同时看 `01` 和 `04`。

## 注意

`团队分工文件` 只是查看副本，修改代码请回到：

```text
F:\c\12\virtual_hil\src
F:\c\12\virtual_hil\include
F:\c\12\virtual_hil\tests
```

否则副本和正式源码可能不同步。
