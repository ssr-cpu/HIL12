# 综合虚拟 HIL 测试台：答辩使用文档

## 1. 项目是什么

这是一个不连接真实硬件的 C17 综合 HIL 测试台。它用纯 C 语言模拟：

- 虚拟 ECU 状态机
- 虚拟 CAN 风格总线
- 信号级故障注入
- 测试脚本执行
- CSV 数据记录
- 测试报告生成

它对应需求文档《案例 12：综合虚拟HIL测试台》，适合 6 人小组结课答辩。

## 2. 项目位置

```text
F:\c\12\virtual_hil
```

网页版位置：

```text
F:\c\12\webapp
```

## 3. 目录结构

```text
virtual_hil/
├─ include/       公开头文件
├─ src/           C17 源码
├─ tests/         自动化测试
├─ examples/      配置、信号、脚本示例
├─ docs/          设计、格式、追踪、角色文档
├─ 团队分工文件/  按 6 个人分类的查看目录
├─ build.ps1      Windows 一键构建
├─ Makefile       Make 构建
└─ CMakeLists.txt CMake 构建
```

## 4. 环境要求

- Windows + MinGW/WSL
- 或 Linux
- 或 macOS
- GCC 或 Clang
- 可选 CMake、GNU Make

本机已使用：

```text
D:\msys64\ucrt64\bin\gcc.exe
```

## 5. 第一条命令：编译

Windows PowerShell：

```powershell
cd F:\c\12\virtual_hil
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Target all
```

如果不想用脚本，可以直接：

```powershell
cd F:\c\12\virtual_hil
New-Item -ItemType Directory -Force build | Out-Null
gcc -std=c17 -Wall -Wextra -Wconversion -Wshadow -Wpedantic -Iinclude src\*.c -o build\hil.exe -lm
```

编译成功后会出现：

```text
F:\c\12\virtual_hil\build\hil.exe
```

## 6. 第二条命令：运行自动化测试

```powershell
cd F:\c\12\virtual_hil
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Target test
```

正常情况下最后一行是：

```text
Total: 34, Failed: 0
```

测试包含正常、边界、异常、故障注入和 12 个端到端用例。

## 7. 第三条命令：运行一个 HIL 测试

```powershell
cd F:\c\12\virtual_hil

.\build\hil.exe run `
  --config examples\default_config.ini `
  --signals examples\signals.csv `
  --script examples\demo.hil `
  --out build\out `
  --lang zh
```

运行后会生成：

```text
build\out\run.csv
build\out\report.md
```

打开报告：

```powershell
notepad build\out\report.md
```

## 8. 第四条命令：查询某个信号

```powershell
.\build\hil.exe query `
  --csv build\out\run.csv `
  --signal engine_speed `
  --from 200 `
  --to 400
```

输出示例：

```text
timestamp_ms,engine_speed
200,0
210,0
...
300,2350
```

## 9. 输入和输出

### 输出文件

| 文件 | 作用 |
|---|---|

## 10. 脚本怎么写

```text
TEST 正常上电
SET throttle_position 25
WAIT 300
ASSERT engine_speed GT 800 1
ASSERT battery_voltage EQ 12.5 0.01
END

TEST 卡死故障
SET throttle_position 30
WAIT 300
FAULT engine_speed STUCK 2000 100
WAIT 20
ASSERT engine_speed EQ 2000 1
RESET
END
```

详细语法见：

```text
docs/file_format.md
```

## 15. 常见问题

### PowerShell 提示禁止运行脚本

使用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Target all
```

### 找不到 gcc

可以尝试本机路径：

```powershell
& 'D:\msys64\ucrt64\bin\gcc.exe' --version
```

### Sanitizer 无法链接

当前 Windows MinGW 缺少 `libasan/libubsan`，请在 WSL 或 Linux 中运行：

```bash
make sanitize
```
